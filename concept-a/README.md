# LineAR Concept A

To set this up, run `npm install` first. Before you set up further, create an
empty folder named `captures` on the root.

If you are able to use Makefiles, input `make run` to set up the local server 
and then open the `index.html` on your browser. 

Otherwise, you can simply input `node server/server.js` and then 
open `index.html` on your browser.

You can manually delete the images saved in the captures folder or run `make clean`.
