# LineAR 
LineAR is a augmented reality training system devised for linear transformation 
learning.

## Dependencies
This system was made in `Python 3.12.6`. As such the dependencies are listed below:
pygame
easyocr
opencv-python (cv2)

## Setting up the application 
You must first install the system's dependencies onto your device. Input the command
`pip install pygame easyocr opencv-python` on your console. After it has finished
installing, you can now run `python client/launcher.py` on this repository's root
folder. If you have the `make` utility, you can simply input `make run` into your
terminal.
